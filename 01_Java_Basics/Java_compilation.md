# Java Source Code 
* Source Code : Contains the program that is to be executed.
* File's Extension : `.java` 

# Java Compiler
* javac compiler is used to execute the java source code into executable code.

# Bytecode
* It is created automatically after execution of Source code by javac.
* Extension : `.class` .
* It has the same name as the source code file name. 

# JVM **( Java Virtual Machine )**
* Already Installed on Windows, other OS we have to install it in order to run java code.
* It is a platform that is required to execute and run the java code on your system.
* Search for `main` function. We have to declare a `public static void main(String[] args)` in our code to get the code executed first.

# JRE **(Java Runtime Environment)**
* It contains all the pre-defined libraries that can be required by user to optimise the code.

# JDK **(Java Development Kit)**
* It is overall collection of `JVM` and `JRE`.
* It is required to be installed beforehand only.
